## The regulatory-finding collection

This collection supports the second evaluation track: retrospective classification of publicly documented findings. It is **not in this repository and not in its Git history**. It lives in a private folder that the lab reads through the `TRIALLAB_RESTRICTED_DATA` setting.

What it holds:

- 52 finding descriptions taken from 39 FDA warning letters.
- Letters dated 2021-01-29 to 2026-08-27, retrieved on 2026-11-16 from fda.gov.
- 22 descriptions about enrollment eligibility, 18 about informed consent, and 12 contrast descriptions about neither.
- 32 of the 39 letters are addressed to a named individual. This is why the collection is private.

What each description is: a short neutral summary of what the letter states, written without names, study names, regulation citations or the category it was filed under. Only this text is ever shown to a system.

Reference labels are **provisional**. They were assigned by the researcher from FDA's wording. No qualified clinical-compliance expert has reviewed them. A warning letter states FDA's observations at a point in time; it is not a final adjudication and may have been answered or closed out later.

The private register records, for each case:

| Field | Content |
|---|---|
| FDA source URL | The letter's page on fda.gov |
| Document date | The date on the letter |
| Retrieval date | When the page was fetched |
| Relevant finding | The neutral summary and short verbatim quotes, each checked against the fetched letter text |
| Evidence available | What concrete facts the published letter gives |
| Issue category | The category the reference label is derived from |
| Label provenance | That the label comes from FDA's stated finding, as read by the researcher |
| Subsequent status | Any response or close-out shown on the FDA listing on the retrieval date |
| Publication rights | Public domain on copyright; personal-data notes per letter |
| Suitability | Whether the case is suitable for evaluation, with caveats |

Rights status (see section 4 of the audit): free to use on copyright grounds; open on privacy. Until the privacy review and the owner's approval in [RELEASE-APPROVAL.md](RELEASE-APPROVAL.md):

- no description, letter reference, letter address or per-case prediction is published;
- the dataset is never sent to an external model provider (`external_processing_allowed: false`);
- results of this track are withheld from every report and export, and are never combined with synthetic results.
